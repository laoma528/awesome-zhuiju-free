## 怎么看评分

首页精选榜单使用 1 至 5 颗 `🌟` 展示推荐指数。推荐指数由「多、快、净、稳」四项体验评分平均后四舍五入得到，方便快速判断；完整结构化评分仍保存在 [`resources/resources.json`](resources/resources.json)。

| 维度 | 你可以这样理解 |
| --- | --- |
| **多** | 资源数量多不多，类型覆盖广不广，更新及时不及时 |
| **快** | 页面打开、搜索响应与播放入口加载快不快 |
| **净** | 广告、弹窗、跳转和诱导下载少不少，越高越干净 |
| **稳** | 能否长期访问，域名与服务是否稳定 |

风险分为版权、安全、隐私和支付四类，并使用 `低 / 中 / 高 / 未知` 标记。详细规则见 [贡献指南](CONTRIBUTING.md)。

## 我们怎么维护

链接会失效，域名会更换，体验也会随时间变化。Awesome Zhuiju Free 不只负责发现资源，还会记录它们是否可用、体验如何，以及可能存在什么风险。

| 持续验证 | 公开评分 | 风险透明 | 社区共建 |
| :---: | :---: | :---: | :---: |
| 每天检测资源有效性 | 用推荐指数快速判断 | 版权、安全、隐私单独标记 | 通过 Issue 和 PR 推荐与纠错 |

> [!IMPORTANT]
> 本项目仅提供资源索引、体验记录与风险提示，不托管影视文件、破解软件、账号、密钥或单部影视作品链接。

## 项目原则

- **持续验证**：收录不是结束，每条记录都应展示最后验证日期。
- **公开透明**：评分、风险、状态变化和投诉处理均保留记录。
- **如实描述**：不因合作、广告或个人偏好修改评分。
- **只做指引**：不托管、不上传、不复制、不销售第三方影视内容。
- **及时处理**：收到有效权利通知、安全报告或失效反馈后及时复核。
